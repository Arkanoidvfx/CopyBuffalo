CopyBuffalo 0.2.4 — Windows 10 / Windows 11, Intel/AMD x64

Программа и установщики называются CopyBuffalo. Внутренние пути ArkCopyBuffer
сохранены для совместимости с существующей историей и настройками.

По умолчанию интерфейс английский. Русский можно выбрать в Settings → View →
Language; перезапустите приложение, чтобы применить выбор.

Скачайте и запустите CopyBuffalo-Full-Setup.cmd: он скачает две части полного
установщика, проверит SHA-256 и откроет установку всех функций с моделью.
Для установки без интернета перенесите CMD и обе части .part1/.part2 вместе.
Меньший CopyBuffalo-Setup.exe нужен только без функции сжатия промптов.

С версии 0.2.3 или старше обновитесь до 0.2.4 вручную один раз: изменилось
имя установщика. Дальнейшие обновления используют CopyBuffalo-Setup.exe.

Запустите первый установщик. Он работает без прав администратора,
создаёт ярлыки и предлагает автозапуск. .NET и FFmpeg уже внутри.
По умолчанию: %LOCALAPPDATA%\Programs\ArkCopyBuffer.
Выберите «Полная установка» — сжатие промптов установится вместе с программой.
Модель, CPU/CUDA-сервер и необходимые DLL включены; интернет не нужен.
Отдельно устанавливать Python, .NET, FFmpeg, Visual C++ или CUDA Toolkit не нужно.

Пользование: копируйте как обычно, открывайте историю по Win+V.
Значок находится в трее (при необходимости раскройте скрытые значки).
Настройки и пауза — в меню трея и в «⋯» панели.
Выход из приложения возвращает стандартный Win+V Windows.

Поддержка: Windows 10 1809+ / Windows 11, 64-битные Intel/AMD.
Рекомендуется обновлённая Windows 10 22H2 или Windows 11.
Windows 7/8, Server, 32-битная Windows и ARM64 в этот комплект не входят.
Сжатие промптов: рекомендуется 16 ГБ ОЗУ. Для RTX 5070 обновите
драйвер NVIDIA с официального сайта. GPU используется при наличии
не менее 8 ГБ свободной видеопамяти; иначе используется CPU.
При ошибке запуска комплектного GPU-сервера приложение пробует CPU.
CPU-сжатие медленнее. После сжатия сервер и модель выгружаются.

История и настройки сохраняются отдельно от программы, поэтому
обновление установщиком их не удаляет. Автообновление включено по умолчанию:
программа проверяет релизы при запуске и каждые 15 минут, скачивает обновление
в фоне и устанавливает его, когда панель закрыта и текущие операции завершены.
В «Настройки → Вид → Обновления» можно выключить автоустановку, проверить
релиз вручную или нажать «Обновить и перезапустить». Модель повторно не качается.
В версии 0.1.0 обновлятора ещё нет: новую версию нужно один раз поставить вручную.
Перед ручной установкой выйдите через трей. История и настройки сохранятся.
Удаление — Параметры Windows → Приложения → CopyBuffalo.
Удаление программы также удаляет компонент AI. История остаётся:
%LOCALAPPDATA%\ArkCopyBuffer; настройки: HKCU\Software\ArkCopyBuffer.
Для полного удаления личных данных удалите их вручную после выхода.

НЕ копируйте history.dat/images со старого компьютера: они зашифрованы
Windows для прежней учётной записи. На втором ПК начнётся новая история.
Папки в истории — ссылки: оригинал должен быть доступен на этом ПК.
Автоматическая вставка в программы, запущенные от администратора,
может блокироваться Windows; используйте Ctrl+V.

Установщики пока не имеют цифровой подписи: Windows/SmartScreen может
показать предупреждение. Проверяйте происхождение файла и SHA256SUMS.txt.
Никогда не отключайте антивирус ради установки.

Базовая программа работает без сети. Сжатие также локальное;
сервер слушает только 127.0.0.1 и останавливается после запроса.
