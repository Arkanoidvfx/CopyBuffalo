# ArkCopyBuffer

История буфера обмена для Windows. Открывается по **Win+V** рядом с курсором ввода и работает из системного трея.

## Скачать и запустить

1. Скачайте `ArkCopyBuffer.exe` из [последнего релиза](https://github.com/Arkanoidvfx/CopyBuffalo/releases/latest).
2. Сохраните EXE в удобную папку и запустите. Установка .NET не требуется; сборка предназначена для Windows x64.
3. Копируйте текст, изображения или файл как обычно. Нажмите **Win+V**, чтобы открыть историю и вставить запись.

В меню значка в трее можно поставить запись на паузу, включить запуск вместе с Windows и очистить историю. В окне доступны поиск, закрепление записей и группы. Для текста поддерживается вставка без форматирования. Для копий графов Unreal Engine и Unity Shader Graph показывается предпросмотр.

Приложение перехватывает **Win+V**. Пока оно запущено, стандартная панель истории Windows по этому сочетанию не открывается. Если перехват недоступен, историю можно открыть из трея.

## Данные

История и изображения хранятся локально в `%LOCALAPPDATA%\ArkCopyBuffer` и защищены средствами Windows для текущей учётной записи. Незакреплённых записей хранится до 100; обычные записи удаляются через 7 дней, краткоживущие — через 1 день. Закреплённые записи сохраняются, пока вы их не удалите. Настройки хранятся в `HKCU\Software\ArkCopyBuffer`.

Удаление EXE само по себе не удаляет историю и настройки. Чтобы удалить данные, сначала выйдите из приложения через трей, затем удалите указанную папку и раздел реестра.

## Сборка из исходников

Нужен .NET 9 SDK на Windows:

```powershell
dotnet publish ArkCopyBuffer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .tmp\release
```

Готовый файл: `.tmp\release\ArkCopyBuffer.exe`.
